1 전기 에너지와 소비 전력

1초 동안 얼마나 쓸까?

② ( 소비 전력 ) : 1초 동안 전기 기구가 사용하는 전기 에너지 [ 단위 : W (와트) ]

= 1W는 전기기구가 1초 동안 1J의 전기 에너지를 소비하는 것

*J(줄) : 에너지의 단위
1J = 1V의 전압으로 1A의 전류가 1초 동안 흐를 때의 에너지

1 전기 에너지와 소비 전력

소비 전력이 크면

= 소비 전력이 클수록 같은 시간동안 더 ( 많은 ) 전기 에너지를 사용한다는 것
1 전기 에너지와 소비 전력

소비 전력 구하기

Q. 어떤 전기 기구가 5초 동안 150J의 전기에너지를 사용한다면 이 기구의 소비 전력은? 150 J ÷ 5 초 = 30 W
소비 전력 = 전기 에너지 ÷ 시간(초)
2 전력량

오래 쓰면 더 많이 쓴다

③ ( 전력량 ) : 소비 전력에 사용한 시간을 곱하여 나타낸 전기 에너지 [ 단위 : Wh (와트시) ]

= 1Wh는 1W의 전력을 1시간 동안 사용하였을 때의 전력량

= 일정 시간동안 소모하는 전기 에너지의 양

소비 전력 시간
2 전력량

전력량을 식으로

전력량 = ( 소비 전력 ) X ( 시간 )
Q. 소비 전력이 5000W인 밥솥을 2시간동안 사용할 때의 전력량은? 5000 W × 2 h = 10000 Wh

10000 Wh = 10 kWh (1 kWh = 1000 Wh)

**전기요금은 보통 1000Wh당 약 100원 → 10 kWh면 약 1000원

3 에너지 전환

2. 전기 에너지의 전환

① 전기에너지는 일상생활에서 열에너지, 빛에너지, 운동에너지, 화학에너지, 소리 에너지 등 다양한 형태로 전환되며 우리의 삶을 편리하게 해준다.
3 에너지 전환

② 일상생활에서 전기 에너지 전환

전기기구에너지 전환
전기밥솥, 인덕션전기에너지 → ( 열 )에너지
세탁기, 로봇청소기전기에너지 → ( 운동 )에너지
LED 전등전기에너지 → ( 빛 )에너지
스피커전기에너지 → ( 소리 )에너지
스마트 기기의 배터리 충전전기에너지 → ( 화학 )에너지
4 효율 · 대기 전력

필요한 에너지로 얼마나 바뀔까?

3. ( 에너지 효율 ) : 전기 기구에 공급한 전기 에너지 중에서 필요한 에너지로 전환되는 비율

*전등 A와 B 중 에너지 효율이 더 높은 것은?

A : 6 J ÷ 12 J = 50 %

B : 6 J ÷ 8 J = 75 %

B가 더 효율이 높다!

4 효율 · 대기 전력

효율이 높은 기구를 고르려면

① 에너지 효율이 높은 전기기구를 사용하면 전기에너지를 더 ( 적게 ) 사용할 수 있다.

② 에너지 소비 효율 등급 : 전기기구의 에너지 소비 효율을 평가하고 등급을 부여하는 제도

- ( 1 )등급에 가까울수록 에너지 효율이 높은 것

- 소비자들이 에너지 절약 전기기구를 선택하도록 돕기 위해 운영되는 제도

4 효율 · 대기 전력

꺼져 있는데도 전기를 쓴다?

4. ( 대기 전력 ) : 전기기구를 실제 사용하지 않을 때 소비하는 전기 에너지

① 대기전력이 ( 적은 ) 전기기구는 에너지를 효율적으로 사용 가능

4 효율 · 대기 전력

② 대기 전력을 줄이는 방법

전원 스위치가 있는 멀티탭 사용
장기간 사용하지 않는 전기기구의 플러그 뽑기
대기 전력 차단 기능이 있는 전기기구 사용하기

⇒ 전기 에너지 생산을 위해 화석연료를 사용하고, 이로 인해 이산화탄소 발생량이 증가하여 지구 온난화 현상이 가속되고 있으므로 전기에너지를 절약하고 효율적으로 사용해야한다.

확인문제

1
표는 전구 A와 B를 1시간 동안 켜 두었을 때 전환된 에너지를 모두 나타낸 것이다. 이에 대한 설명으로 옳은 것을 <보기>에서 모두 고른 것은?

구분AB
빛에너지48000 J36000 J
열에너지16800 J28800 J
정답 ⑤ · A와 B 모두 1시간 동안 쓴 전기 에너지가 48000 + 16800 = 36000 + 28800 = 64800 J로 같으므로 소비 전력도 같아요(ㄱ ○). 필요한 빛에너지 비율은 A가 48000 ÷ 64800 ≈ 74 %, B가 약 56 %라 A의 효율이 더 좋아요(ㄴ ○). 전구에서는 전기 에너지가 빛과 열에너지로 바뀌어요(ㄷ ○).

보기

ㄱ. A와 B의 소비 전력은 같다.

ㄴ. 에너지 효율은 A가 B보다 좋다.

ㄷ. 전구에서는 전기 에너지가 빛에너지와 열에너지로 전환된다.

2
전기기구에서 일어나는 에너지 전환을 나타낸 것으로 옳지 않은 것은?

정답 ④ · 드라이어는 뜨거운 바람을 내므로 전기 에너지 → 열에너지, 운동 에너지로 전환돼요. 전기 에너지 → 화학 에너지는 배터리를 충전할 때예요.
